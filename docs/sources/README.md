# Sources

Everything the game asserts about Dhaka should trace to a row here. One file per source, `S-0nn-slug.md`,
with a metadata table, numbered facts and, where we have it, the archived text. `FACTS.md` indexes the facts
by topic with a confidence grade; `ENTITIES.md` lists companies, places, people and terms for naming things.

**Citing.** In docs, code comments, voice-line notes and tuning tooltips write the fact id, e.g. "the first
door takes the kerb (S-017.7, S-013.5)". A whole source is `S-013`; a fact is `S-013.5`. Grades in
`FACTS.md`: **A** two or more independent sources, **B** one published source or a named speaker, **C** a
snippet, a machine translation or an inference.

**Adding a source.** Next free number; metadata table (outlet, date, language, URL, how obtained,
reliability); facts as `- **S-0nn.m** …` with the original-language quote and a translation for anything
quotable; archived text below a note on copyright. Then add rows to `FACTS.md` (never delete, mark
superseded) and names to `ENTITIES.md`. Owner statements go in `S-024`; new ones get the next number there.

**Why keep what seems irrelevant.** The six rival intercity companies, the rest stop by Mirpur Ceramics, the
conductor's Tk 70 meal money, the student who paid half for his mother: none of it is needed today and all
of it is the kind of detail a later scene will want. Record first, judge later.

**Copyright.** Archived article texts are for research inside this private repository. Quote short passages
with attribution in the game and its docs; do not republish the texts.
